## Tweet 7/9 (the tech)

Stack:
- Python + FastAPI backend
- React + TypeScript frontend
- pywebview desktop shell
- diffusers + torch for real diffusion
- Ollama for chat
- SQLite for memory
- PyInstaller for the bundle

No Tauri. No Electron. No 200MB browser.

The .app is 283MB. That's mostly torch.
